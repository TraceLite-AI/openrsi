# 有方向的自我改进 vs 随机游走（已知最优解的玩具问题）

这个实验回答一个问题：给自我改进循环加上"方向"（组内比较、动量、统计检验），能不能比现在的循环更快、更稳地变好。
玩具问题的最优解已知，所以能直接算出每个版本的**真实**答对率，不用靠带噪声的考试分来猜。

```bash
python benchmarks/directed_toy/directed_toy.py --budget 6000 --seeds $(seq 0 19) \
    --q 0.35 --collateral 0.7 --break-bias 0.8
```

## 设置

- 被进化的是 12 个"位置"，每个取 good / neutral / bad，各位置权重不同（两个完全无关）。真实答对率起点 0.39，最优 0.85。
- 单个位置的效果只有 2～10 个百分点；考试题 30 道、练习题每代 30 道，每题做一次。噪声和效果同一个量级。
- agent 答错时报一个原因，只有一半概率指对。
- 提案器模拟 LLM：`q` 是"沿方向改对"的概率，`collateral` 是"顺手改动别处"的概率，`break_bias` 是顺手改动把东西改坏的概率。
- 每组每个种子 6000 次 agent 调用，20 个种子。最终版本 = 考试分最高的已接受版本，按公式算它的真实答对率。

| 组 | 做法 |
|---|---|
| A | 现在的循环：看一道错题的归因就改，考试分变高就收 |
| B | A + 考试题上的逐题配对检验（z ≥ 1.645） |
| C | 有方向（`loop.directed` 默认）：每组 3 个方向各 1 个修改，带"不改"对照在同一批练习题上比，最好的修改送去考试准入；动量决定下一组试哪些方向 |
| D | C + 每个方向 2 个修改（嵌套方差分析）+ 线搜索步长 |

A、C、D 的考试准入相同，差别只在候选怎么产生、怎么挑。

## 结果（synthetic toy，非 benchmark）

"相对 A"是 20 个种子上逐种子配对的差值，± 是标准误。

| 提案器 | 组 | 最终真实答对率 | 相对 A | 接受的改动里真实变差的比例 |
|---|---|---|---|---|
| 较好（q 0.6，collateral 0.5，break 0） | A | 0.730 ± 0.102 | — | 6.1% |
| | B | 0.457 ± 0.066 | −0.273 ± 0.028 | 0.0% |
| | C | 0.751 ± 0.055 | +0.021 ± 0.026 | 3.3% |
| | D | 0.717 ± 0.093 | −0.013 ± 0.028 | 5.0% |
| 一般（q 0.35，collateral 0.7，break 0.8） | A | 0.631 ± 0.074 | — | 8.9% |
| | B | 0.432 ± 0.053 | −0.199 ± 0.023 | 7.1% |
| | C | 0.652 ± 0.095 | +0.021 ± 0.029 | 4.8% |
| | D | 0.603 ± 0.090 | −0.028 ± 0.025 | 6.0% |
| 很差（q 0.2，collateral 0.9，break 0.9） | A | 0.581 ± 0.091 | — | 13.1% |
| | B | 0.413 ± 0.040 | −0.168 ± 0.019 | 10.0% |
| | C | 0.616 ± 0.097 | +0.035 ± 0.020 | 5.3% |
| | D | 0.552 ± 0.069 | −0.029 ± 0.027 | 11.0% |

## 结论

1. **考试题少时，严格的显著性准入（B）最差**：30 道题检不出几个百分点的提升，几乎什么都收不进来，三种设定下都比 A 低 0.17～0.27（z ≈ −9）。
2. **有方向（C）和现在的循环（A）持平，提案器越差优势越明显**（+0.021 → +0.035，最好的一档 z = 1.73，还不算显著），
   接受的坏改动大约少一半（13.1% → 5.3%）。
3. **D 的额外部件在这里不划算**：每个方向多写一个修改、再做线搜索，成本翻倍，换来的统计确定性没有变成更好的结果。
   所以 `loop.directed` 默认每个方向 1 个修改、不做线搜索；这两样保留为可选项。
4. 实现过程中试过、被实验否定的做法：只在"方向平均显著好"时才送修改去准入（提案器质量差时方向的平均效果被拖到 0，
   永远检不出来）；把 Bonferroni 摊到整个运行（门槛太高）；"连续几组没检出就算收敛"（把证据不足当成到头了）。
   现在的做法：方向只决定往哪里多试，收不收看单个修改；证据跨组累积；收敛要求"有把握没有方向能提升 δ 以上"。

这是玩具问题：效果大小、噪声、提案器的行为都是设定的。它说明了各部件在什么情况下有用，不代表真实 agent 上的数字。
